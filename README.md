An entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)
bounty on make.fun. The task: write one sentence pitching a ridiculous
invention that fixes a tiny everyday annoyance, and let a house judge rank
it on funny, clever, and original.

## The pitch

Crumbs fall between keyboard keys and stay there forever, mocking you with
every keystroke. This entry answers with the Crumb Butler: a tiny robot
living inside your keyboard that vacuums up every lunch crumb and mails
your sandwich a strongly worded invoice for littering. The annoyance is
small, the invention is absurd, and the sandwich gets the bill it deserves.

## How it works

`main.py` is a small deterministic Python program using only the standard
library. It writes the pitch — exactly one sentence, 159 characters — to
`/output/entry.txt`. Running it twice produces byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
